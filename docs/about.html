About

One story, every side

Most world-news briefings show you one lens. Geopolitical Daily reads 87 news sources in 15 perspective groups every day and shows how each part of the world covers the same event — with every source linked and state media clearly labeled.

How it is made

Issues are written by an AI model and published automatically; no person reviews an issue before it goes out. The model's work is then checked by code: quotes must match the source text, repeated stories are held back, links must point at what they claim to. The whole process, with the numbers from the latest run, is on How it works; cost and quality figures for every issue are on the dashboard.

State-affiliated outlets are part of the picture on purpose. They show how a government wants an event to be seen. They are always labeled and never used as the only source for a fact.
